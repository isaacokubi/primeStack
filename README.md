# primeStack

Premium MERN software product company website and content platform.

## Stack
- React + JavaScript + Vite
- Tailwind CSS
- React Router
- Framer Motion
- Axios
- Node.js + Express + JavaScript
- MongoDB + Mongoose
- JWT + HTTP-only cookies
- Cloudinary-ready media storage

## Architecture
The product portfolio is data-driven. Products, blog posts, case studies, jobs, testimonials, contacts and site content are managed through the API/admin dashboard rather than hardcoded into individual public pages.

## Public routes
/, /products, /products/:slug, /services, /about, /case-studies, /case-studies/:slug, /technology, /blog, /blog/:slug, /careers, /careers/:slug, /contact, /privacy, /terms, /security

## Admin
/admin

Roles: Admin and Editor.

## Development
Client and server are separate JavaScript applications. Copy the example environment files, install dependencies in both directories, seed the admin account/data, then run the client and server development scripts.
